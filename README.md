# Rock, Paper, Scissors

A simple Rock, Paper, Scissors game built with Python where you play against the computer.

## Features
- Play against the computer.
- Random computer choices.
- Input validation.
- Tracks wins for both the player and the computer.
- Type `quit` to exit the game.

## Requirements
- Python 3

## How to Run
1. Clone or download this repository.
2. Open the project folder in your terminal.
3. Run the following command:

```bash
python3 main.py
```

## How to Play
- Enter `rock`, `paper`, or `scissors` to make your choice.
- The computer randomly selects its choice.
- The game displays the result and updates the scores.
- Type `quit` to exit and see the final scores.

## Technologies Used
- Python
- Random module
